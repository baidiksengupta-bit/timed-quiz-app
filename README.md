# ⚡ Timed CS Quiz App

An interactive, responsive Computer Science quiz application built with vanilla JavaScript, modern CSS glassmorphism, and HTML5. Players answer foundational CS and web development questions against a 10-second countdown timer per question.

---

## 🎮 Live Preview

Check out the live demo here: **[Play the Quiz](https://github.com/baidiksengupta-bit/timed-quiz-app/)**  

---

## 🌟 Key Features

* **Real-Time Countdown Timer:** Non-blocking 10-second timer per question powered by `setInterval`.
* **Automatic Timeout Handling:** Moves to the next question automatically if the timer runs out.
* **Score Tracking:** Live score counter that calculates your total points out of 20 questions.
* **Modern Glassmorphic UI:** Frosted glass effect with radial background gradients, neon choice badges, and responsive card sizing.
* **Pure Vanilla Stack:** Zero frameworks, zero external dependencies—lightweight and runs directly in any modern browser.

---

## 🛠️ Built With

* **HTML5:** Semantic page structure and layout.
* **CSS3:** Flexbox, glassmorphism (`backdrop-filter`), CSS transitions, and responsive media queries.
* **JavaScript (ES6+):** DOM manipulation, state management, array operations, and asynchronous timers (`setInterval` / `clearInterval`).
